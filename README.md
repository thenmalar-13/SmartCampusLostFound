Smart Campus Lost & Found 📱🎓
An Android application designed to help students and campus staff easily report, discover, and claim lost or misplaced items around the university campus.

✨ Features
Report Lost Items: Post details, descriptions, and locations of items you've lost on campus.

Browse Found Items: View a dynamic list of items found by others, complete with status tags and item images using a smooth RecyclerView adapter (ItemAdapter).

Contact & Management: Easily connect with finders or remove listings once items are recovered.

Campus Integration: Built with modern Android development standards to provide a fast and reliable user experience.

🛠️ Tech Stack & Architecture
Language: Java

UI Components: RecyclerView, CardView, Custom Adapters, XML Layouts

Database & Services: Firebase / Real-time backend integration (google-services.json)

IDE: Android Studio

🚀 Getting Started
Clone the repository:

Bash
git clone https://github.com/thenmalar-13/SmartCampusLostFound.git
Open the project in Android Studio.

Sync the project with Gradle files.

Add your own google-services.json file inside the app/ directory if configuring Firebase from scratch.

Build and run the app on an Android emulator or a physical device!
